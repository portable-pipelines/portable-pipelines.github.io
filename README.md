# Portable Pipelines website

This repository is the source of the public website for Portable Pipelines. GitHub Pages serves it from the `main` branch. The site root is the repository root.

There is no build step, no framework, and no CDN.

## Files

- `index.html`: page content
- `styles.css`: layout and theme
- `images/logo.svg`: mark and favicon
- `.nojekyll`: tell GitHub Pages not to process the site with Jekyll

Edit the HTML and CSS, then push to `main`.
